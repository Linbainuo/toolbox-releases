# 林白糯工具箱

林白糯工具箱的官方版本发布与更新下载仓库。

## 下载

请在 [Releases 发布页](https://github.com/Linbainuo/toolbox-releases/releases) 下载 `LinBainuoToolbox.exe`。

如果发布页暂时没有安装包，表示首个版本仍在准备中。

本仓库仅用于发布成品、版本信息与更新说明，不上传工具箱界面的项目源码。

## 更新

接入更新功能的工具箱会在启动后检查已发布的版本。也可以打开 **设置 → 工具箱更新 → 检查更新**。

发现新版后，点击 **下载新版** 并选择保存位置。下载完成且校验通过后，退出旧版，再运行新版工具箱。

测试版使用递增的构建号识别更新，界面显示的版本名可能保持不变。

## 运行环境

Windows 10 / 11，.NET Framework 4.8。

工具箱与各插件的版本分别维护；具体软件兼容性以工具箱中的插件说明为准。
